# WeatherApp

# 🌦️ Dynamic Weather App

A simple, real-time, location-based weather dashboard that fetches and displays current weather conditions using the **OpenWeatherMap API** and the **Geolocation API**.

🔗 **Live Demo:** [weatherappdetector.netlify.app](https://weatherappdetector.netlify.app/)

---

## 🚀 Features

- 🌍 Real-time location detection using Geolocation API
- 🌡️ Displays current temperature, weather conditions, and location
- ☁️ Fetches data from the OpenWeatherMap API
- 💻 Clean, responsive user interface
- 📱 Mobile-friendly layout

---

## 🛠️ Technologies Used

- **HTML**
- **CSS**
- **JavaScript**
- **OpenWeatherMap API**
- **Geolocation API**
- **Netlify** (for deployment)
